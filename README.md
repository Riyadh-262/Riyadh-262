## Current Research (Thesis)

**Benchmarking Multi-Label Loss Functions, Calibration, and Threshold Optimization for 12-Lead ECG Arrhythmia Classification under Class Imbalance**

| | |
|---|---|
| **Problem** | ECG datasets are heavily imbalanced, and a single patient can have several conditions at once (multi-label). Standard training often gives overconfident, poorly calibrated predictions on rare classes. |
| **Approach** | Compare multi-label loss functions, apply probability calibration, and optimize per-class decision thresholds. |
| **Evaluation** | Macro-F1, AUROC, and calibration quality (reliability curves, ECE) rather than accuracy alone. |
